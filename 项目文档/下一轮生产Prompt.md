### 任务 1（P0）：视觉伺服闭环 —— 从开环变真闭环

**现状**：`软件/atri/atri/skills/carry.py` 和 `kick.py` 都是 `perceive()` 一次 → 直接执行动作。

**要求**：

1. 重构 `carry.py` 和 `kick.py`，实现**迭代式视觉伺服闭环**：
   ```
   循环（最多 max_iter 次 或 超时 timeout_s）：
       感知 → 计算误差 e = (Δx_cm, Δy_cm, Δθ_deg)
       if |e| < 阈值: 收敛，break
       步长 = clamp(gain × e, -max_step, +max_step)   # 饱和限幅防振荡
       小脑执行一步微调
       记录本轮误差
   ```
2. 必须处理三种异常，并记录原因而非静默失败：
   - **振荡**：误差在阈值附近来回摆 → 降低增益
   - **目标丢失**：视觉短暂丢失 → 原地转头扫描 + 用上轮位置预测，不立即放弃
   - **不收敛**：达到迭代上限 → 安全退出并上报 `status="not_converged"`
3. 改造 `软件/atri/atri/perception/mock.py`：Mock 目标必须**带初始偏移和噪声**，并能随机器人动作产生**反馈变化**（当前 Mock 直接返回固定值，闭环跑起来是假的）。
4. 新增单元测试：收敛路径、振荡保护、目标丢失恢复、不收敛上报。

**交付**：
- 收敛日志，形如：`误差: 12.3cm → 7.1cm → 3.2cm → 0.9cm (收敛, 4轮)`
- 导出 CSV（每轮误差序列）
- 收敛曲线图（matplotlib）
- 对比数据：**开环 vs 闭环**的成功率差异

### 任务 3（P1）：ZMP 步态 —— 让"倒立摆"从 PPT 走进代码

**现状**：`cerebellum.py:generate_gait()` 用两条腿独立的正弦波，`max(0, sin)` 半波整流，躯干 pitch/roll 是随手加的正弦扰动。**没有任何 ZMP 计算**。

**要求**：

1. 实现 **LIPM（线性倒立摆模型）**：
   - 动力学：`ẍ = ω²(x - p)`，其中 `ω = √(g/z_c)`
   - 由期望 ZMP 轨迹 **解析反解** CoM 轨迹（纯数学，无需机器学习）
2. 用 **三次样条或摆线** 替代正弦做摆动腿轨迹，保证速度/加速度连续（消除半波整流的突变）。
3. 加 **IMU 反馈补偿**：实测姿态偏差 → 修正踝关节目标角。
4. 输出 **ZMP 稳定裕度**数据：质心投影到支撑多边形边界的最小距离，逐步记录。
5. 步态参数扫描：**步长 × 周期 → 稳定/失稳**，产出一张相图。

**交付**：
- ZMP 与 CoM 轨迹图
- 稳定裕度时间序列
- 步态参数-稳定性相图
- 说明取舍：为什么踝关节只保留 pitch（重量/成本 vs 横滚靠髋关节补偿）
