## 任务 1（Day 1，最高优先级）：视觉伺服迭代闭环

**目标**：把 `carry` / `kick` 从"感知一次 → 执行动作"的开环，改成"感知 → 微调 → **再感知** → 达标才执行"的迭代闭环，并产出真实收敛数据。

### 1.1 改造 `软件/atri/atri/perception/mock.py`

当前 Mock 返回**固定值**，导致闭环是假的。必须改成：

- 支持设定**目标初始位置**（横向偏移 `x_cm`、距离 `distance_cm`）
- 叠加**可控噪声**（高斯或均匀，种子固定以保证可复现）
- **随机器人动作反馈变化**：机器人朝向/位置变化后，感知到的目标坐标要相应改变
- 支持模拟**目标丢失**（按概率或按指定帧数返回 None）

### 1.2 改造 `软件/atri/atri/skills/carry.py` 和 `kick.py`

实现迭代闭环：

```
for i in range(max_iter):
    obs = perceive(target)
    if obs is None:            # 目标丢失
        执行搜索（转头扫描 + 用上轮位置预测）
        continue
    e = 计算误差(obs)          # Δx_cm, Δy_cm, Δθ_deg
    log(轮次, e)
    if |e| < 阈值(converged_tol):
        标记收敛; break
    step = clamp(gain * e, -max_step, +max_step)   # 饱和限幅
    执行一步微调(step)
else:
    # 未收敛
    return {"status": "not_converged", "history": ..., "reason": ...}
```

**必须处理的三种异常**（记录原因，不静默失败）：

| 异常 | 检测方式 | 处理 |
|---|---|---|
| 振荡 | 误差在阈值附近反复变大 | 降低增益 `gain *= 0.5` |
| 目标丢失 | `perceive()` 返回 None | 扫描 + 位置预测，不立即放弃 |
| 不收敛 | 达到 `max_iter` | 安全退出，上报 `not_converged` |

**参数必须可配置**（阈值、增益、最大步长、最大迭代数、超时），写在技能参数或 `config/robot.json` 里。

### 1.3 新增单元测试 `tests/test_servo_loop.py`

必须覆盖：
- 正常收敛路径（误差单调下降）
- 振荡保护（增益自动降低后收敛）
- 目标丢失后恢复
- 不收敛正确上报
- 超时保护

### 1.4 产出收敛数据

新建 `软件/atri/atri/analysis/servo_bench.py`：
- 批量跑 N 次闭环（不同初始偏移）
- 导出 CSV：`run_id, initial_offset_cm, iterations, final_error_cm, converged`
- 纯标准库实现
