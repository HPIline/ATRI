> 状态：报名与方案设计阶段。本文使用“设计目标/当前状态/后续计划”口径，避免与尚未完成的样机状态混淆。

## 1. 设计目标

A.T.R.I. 是一台面向人形机器人专项小人形组的桌面双足机器人。设计目标：

- 身高 ≤ 60 cm，体宽 ≤ 30 cm，单侧臂长 ≤ 30 cm；
- 自由度：**22 DOF**，双腿各 5（髋 3 + 膝 1 + 踝 1 = 5）、双臂各 4（肩 2 + 肘 1 + 夹爪 1 = 4）、躯干 2、头部 2；
- 传感器：IMU、单目摄像头、麦克风、扬声器；
- 电源：锂电池，电压 ≥ 7.4 V；
- 运行：默认离线，识别、决策、执行全部本地完成。

## 2. 系统架构

```
任务卡 JSON
   ↓
大脑（Brain）: FSM + 技能库 + 任务调度
   ↓                       ↑ 感知结果
小脑（Cerebellum）: 步态生成 / 关键帧动作 / 舵机控制
   ↓
22 路总线舵机 + IMU 闭环
```

- **大脑**：运行在边缘计算板，负责视觉/语音感知结果接入、二维码 JSON 解析、FSM 状态流转。
- **小脑**：设计由 STM32 + 6 轴 IMU 承担步态、姿态闭环与舵机控制；当前先用脚本动作库和 Mock 舵机在纯 Python 中验证。
- **任务统一入口**：JSON 任务卡定义 `face/qr/carry/kick/dance` 五类赛题任务。
- **动作库**：关键帧 JSON 规范（`action_library/`），Webots 标定后导出，`Cerebellum.play_action()` 回放。

## 3. 视觉感知（Mac 已实现接口）

`atri/perception/` 提供统一感知接口：

| 能力 | 接口 | Mock | OpenCV 实现 |
|---|---|---|---|
| 人脸检测 | `detect_face(frame)` | 返回预设姓名/置信度 | Haar Cascade，输出 bbox |
| 二维码解析 | `detect_qr(frame)` | 返回预设 JSON payload | `QRCodeDetector` + JSON 解析 |
| 球检测 | `detect_ball(frame)` | 返回 x_cm/distance_cm | HSV 颜色分割 + 最大轮廓 |

当前状态：接口、Mock 与 OpenCV 代码已编写并通过单元测试；真实摄像头联调计划在 Windows/样机阶段进行。

## 4. 语音交互（Mac 已实现接口）

`atri/voice/` 提供：

- `KeywordRecognizer`：离线关键词识别接口，当前以 `MockKeywordRecognizer` 提供确定性关键词；
- `TTS` 接口：`MockTTS`（内存记录）、`MacOSTTS`（macOS `say` 命令）；
- `VoiceService`：识别 → 应答 → 播报组合入口。

后续 Windows 可接入 Vosk / sherpa-onnx 等离线关键词引擎，不需要改上层技能代码。`Brain` 已支持注入 TTS，`run_demo.py` 默认使用 `MockTTS`。

## 5. 二维码 JSON 指令

`atri/qrgen.py` 生成“内嵌 JSON 指令”的二维码（如 `{"action":"walk","steps":3}`）。

```bash
cd 软件/atri
python3 -m atri.qrgen --action walk --steps 3 --output qr_walk.png
```

依赖：`pip install "qrcode[pil]"`（可选）。
