## 一、总目标

把当前"**骨架模型**"升级为"**可出图、可打印、可装配**"的工程模型：

```
现状：23 个长方体 + 22 个关节           →  只能说"拓扑对了"

      + 2D 工程图 + STL + 干涉校核      →  能说"想清楚怎么造了"
```

**三条主线**：
1. **外观** —— 从长方体变成有造型的壳体与关节模块
2. **尺寸** —— 从外包络细化到壁厚/配合/安装接口
3. **零件** —— 从 link 拆到零件，带编号、材料、工艺

## 二、任务 1：几何基元扩展（外观的基础）

### 2.1 现状问题

`robot_model.json` 里所有 link 的 `geometry.type` 都是 `"box"`：

```json
{"name": "left_thigh", "geometry": {"type": "box", "size_mm": [45,45,80]}}
```

长方体无法表达圆角、圆柱关节、球壳。

### 2.2 要求：支持多种几何基元

扩展 `geometry` 字段，支持以下类型（**全部可用纯数学生成网格**）：

| type | 参数 | 用途 |
|---|---|---|
| `box` | `size_mm: [x,y,z]` | 已支持，保留兼容 |
| `rounded_box` | `size_mm`, `fillet_mm` | 外壳、机身 |
| `cylinder` | `radius_mm`, `height_mm`, `axis` | 舵机本体、关节轴 |
| `sphere` | `radius_mm` | 球形关节壳 |
| `capsule` | `radius_mm`, `length_mm`, `axis` | 连杆（带圆头） |
| `sphere_shell` | `outer_r_mm`, `inner_r_mm` | 关节外壳（中空球） |

**兼容性要求**：
- `box` 必须继续可用（现有测试依赖它）
- `gen_urdf.py` 遇到非 box 类型时，**visual 用真实几何、collision 用等效 box**
  （碰撞用简化体是标准工程做法，且避免仿真变慢）
- 更新 `gen_urdf.py` 支持 `cylinder` / `sphere` 的 URDF 原生标签

### 2.3 造型语言（借鉴 `hardware-exploded.png`）

参考 `材料汇总/deepseek-harness/A.T.R.I.-宣传PPT-v2/assets/hardware-exploded.png`
的造型范式（**只借鉴拓扑与造型语言，尺寸完全不可用**）：

1. **球形关节壳**：每个关节用球壳包住舵机 → `sphere_shell`
2. **串联双舵机**：肩部/髋部的 2 DOF 用两个圆柱垂直串联
3. **模块化连杆**：大腿/小腿/上臂为胶囊或圆角长方体
4. **躯干分层**：胸腔（装板+电池）+ 腰部模块
5. **独立足底板**：矩形足底，前端略上翘
6. **头部**：圆角方块 + 正面屏幕区 + 摄像头孔 + 麦克风孔

### 2.4 交付

- [ ] `geometry` 支持 6 种基元
- [ ] 23 个 link 全部改用合适的基元（不再全是 box）
- [ ] `gen_urdf.py` 正确导出 cylinder/sphere
- [ ] 单元测试：每种基元的参数校验 + URDF 导出正确
- [ ] **兼容性测试：旧 box 模型仍能通过校验**

## 三、任务 2：零件级拆分 + 编号 + BOM

### 3.1 现状问题

一个 link = 一个零件，无法制造。真实机器人一个"大腿"至少包含：
壳体、舵机支架、轴、轴承、螺钉若干。

### 3.2 要求：新增零件清单 `design/parts/part_list.json`

**零件编号规则**（简单、可读、可扩展）：

```
ATRI-<部位>-<序号>
部位代号：
  HD 头部      TR 躯干      PL 骨盆
  LL 左腿      RL 右腿
  LA 左臂      RA 右臂
  EL 电气      FA 紧固件
示例：ATRI-LL-001 = 左腿大腿壳体
      ATRI-FA-003 = M3×8 内六角螺钉
```

**每个零件必须包含**：

```json
{
  "part_no": "ATRI-LL-001",
  "name": "左大腿壳体",
  "belongs_to_link": "left_thigh",
  "qty_per_link": 1,
  "qty_total": 1,
  "material": "PETG",
  "process": "FDM",
  "mass_g": 42.0,
  "geometry": {"type": "capsule", "radius_mm": 22.0, "length_mm": 60.0, "axis": "z"},
  "print": {
    "layer_height_mm": 0.2,
    "wall_count": 3,
    "infill_percent": 50,
    "supports": false,
    "orientation": "沿 Z 轴竖直打印"
  },
  "interfaces": [
    {"type": "servo_mount", "servo": "STS3215", "hole_pattern": "M2.5, 30x10mm"},
    {"type": "bearing_seat", "bearing": "MF105ZZ", "fit": "H7"}
  ],
  "notes": "承力件，填充 50%"
}
```

**要求**：
- 每种零件**左右对称要分开编号**（左腿/右腿是不同零件）
- 紧固件单列（螺钉、螺母、垫片），标明规格与用量
- 标准件（轴承、舵机）标明型号
- 质量合计必须与 `robot_model.json` 的 link 质量**对得上**（允许 5% 误差并注明）

### 5.3 绘图技术要求

- **纯标准库**生成 SVG
- 正交投影（正/侧/俯），**不是**透视
- 必须有：图框、标题栏（项目名/图号/比例/日期/单位）、尺寸线、标注文字
- 尺寸单位统一 **mm**，比例标注（如 1:5）
- 中文标注（SVG 里用系统字体，`font-family="PingFang SC, Helvetica"`）

### 5.4 正交投影的数学

对每个 link 的几何体，投影到三个平面：

```
正视（Front）： 投影到 XZ 平面（看 Y 方向）  → 显示宽度与高度
侧视（Side）：  投影到 YZ 平面（看 X 方向）  → 显示厚度与高度
俯视（Top）：   投影到 XY 平面（看 Z 方向）  → 显示长宽
```

每个几何体只需投影其包围盒（box/rounded_box/capsule）或圆（cylinder/sphere），
**不需要真 3D 渲染**——工程图本来就是线框投影。

## 七、任务 6：干涉与间隙校核

### 7.1 为什么需要

双足机器人在**极限姿态**下，大腿和小腿、手臂和躯干可能打架。
这是只有做过真实设计的人才会考虑的问题——**写进材料很加分**。

### 7.2 要求

新增 `design/check_interference.py`：

1. 对每个关节，取**限位两端 + 中间**三个姿态
2. 计算各 link 的轴对齐包围盒（AABB）在**该姿态下的实际位置**（沿运动链变换）
3. 检测**非相邻** link 之间的 AABB 重叠
4. 输出冲突清单：哪两个 link、在什么角度、重叠多少

**注意**：AABB 是保守估计，会误报。所以：
- 报告要区分"**确凿冲突**"（重叠量大）和"**疑似冲突**"（刚接触）
- 明确说明这是**包围盒级检查，不是精确几何干涉**

### 7.3 交付

- [ ] `design/check_interference.py`
- [ ] `design/drawings/interference_report.md`（冲突清单）
- [ ] 若有冲突：给出**修正建议**（改限位 or 改尺寸）
- [ ] 测试：已知会冲突的构造用例能被检出

## 十一、约束

1. **纯标准库优先**。`atri/` 包**禁止**引入第三方依赖；`design/` 可用 numpy/trimesh 但**必须可选**（未安装时降级运行）。

3. **单位纪律**：模型 mm、URDF m、角度内部 deg / URDF rad，转换处写注释。
4. **关节名/编号/限位以 `软件/atri/atri/config.py` 为准**，不得自创。
5. **不改** `brain.py` / `fsm.py` / `task_card.py` / `cerebellum.py` 的核心逻辑。
6. **禁止 force push**；改动前 `git pull --rebase origin main`。
7. STL 大文件若超 50 MB 不入库，放网盘 + 仓库内说明。

## 十二、时间不足时的优先级

按"**评委最可能追问 × 实现成本**"排序：

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | **22 关节编号图** | 评委必问，成本最低，纯 2D 投影 |
| **P0** | **几何基元扩展**（任务 1） | 外观与后续一切的基础 |
| **P1** | **三视图 + 尺寸链图** | 材料必交 |
| **P1** | **零件拆分 + BOM** | 证明"真算过怎么造" |
| **P2** | **干涉校核** | 体现工程深度，加分项 |
| **P2** | **STL 导出** | 只有要真打印才必需 |
| **P3** | **爆炸图 / 等轴测图** | 锦上添花 |

**如果只做一件事：出 22 关节编号图。**
**如果只做两件事：再加几何基元扩展。**
**如果只做三件事：再加零件拆分 + BOM。**
