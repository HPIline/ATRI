## 软件栈（软件/atri）

“大脑—小脑”双层架构 + JSON 任务卡 + FSM + 五项技能 + **脚本动作库/步态生成**（已弃用 VLA）。
核心代码 **仅依赖 Python 3.9+ 标准库**，无硬件、无 GPU 也能跑通全流程。

已新增：
- `atri/perception/`：视觉感知接口 + Mock + OpenCV 实现（人脸/二维码/球）
- `atri/voice/`：离线关键词识别接口 + TTS（Mock / macOS say）
- `atri/qrgen.py`：二维码 JSON 指令生成器
- `action_library/`：动作库 JSON 规范 + 示例 + 校验/回放

```bash
cd 软件/atri

# 编译检查
python3 -m compileall -q atri run_demo.py && echo "compile OK"

# 单元测试（当前 168 项）
python3 -m unittest discover -s tests

# 无硬件闭环演示（五项任务卡；--fast 跳过 sleep 用于快速自检）
python3 run_demo.py --fast
```

## ✅ 已决策：新架构 v2（2026-09-11）

**原"路线分歧"已收敛。** 处置办法：把整机尺寸对齐到量产参考机
（幻尔 TonyPi Pro，373 mm / 1.8 kg / 20 DOF），把模型质量从"结构占位预算"改成**真实分布**，
再于 v3 **把数据口径切到协作者 CAD 实装测量**（提交 6d4b077）。
完整参数见 **`design/handoff/新架构参数总表.md`**。

| 项 | v1 | **v2**（历史口径，保留作追溯） |
|---|---|---|
| 身高 × 宽 × 厚 | 475 × 190 × 123 mm | 418 × 223 × 129 mm（CAD 实装 v3 虚高值）；基元口径 373 mm |
| 整机质量 | 2263 g（实口径） | 3437 g（结构件按当时口径 1790 g） |
| link 质量口径 | 结构占位 1650 g，**不含舵机/电子件** | **结构 + 舵机 + 电子件 + 线束**（URDF 可直接做刚体动力学） |
| 最大关节需求 | trunk_roll 1.29 / 腿 1.11 N·m | **trunk_roll 1.26 / 腿 1.05 N·m** |
| 扭矩判据 | "额定 1.0 N·m"（无权威出处） | 堵转 × 50% = 1.47 N·m（参考机选型习惯） |
| 结论 | 115% 额定，余量耗尽 | **腿 111% ❌ 超标**，必须执行减重路径 A/B/C |

> **⏱ 现行 CAD 口径（2026-09-12，第 5 轮之后本轮实测）**
> 上表 3437 g / 1790 g / 418 × 223 × 129 mm 是「舵机 35 与 24.7 用反」时期的**历史口径**（v3 虚高值，见 `design/handoff/装配一致性修正记录.md` §4.4）。
> 修正链：结构 1790 g →（第 1 轮修正）1404 g →（第 5 轮新增件 +86 g）**1490 g / 81 件（实算）**；
> 整机 3437 g → 3050 g → **≈3136 g（纸面推算，重量方案未定案）**；
> 包络 **146 × 263 × 407 mm（深×宽×高，实测）**；踝关节 **1.492 N·m**。
> **扭矩判据已换【官方】额定 0.98 N·m**（DFRobot SER0070 + 飞特 STS3235 规格书双重印证）：
> 按官方口径踝 152%、trunk_roll 194%；历史『堵转×50% = 1.47 N·m』比官方额定**乐观 50%**，仅作并列参考。
> 权威过程记录：`design/handoff/装配一致性修正记录.md`、订正留档 `design/handoff/过期口径修正记录.md`。
> `robot_model.json` / `新架构参数总表.md` 已按本轮实测回灌（v3.1）；URDF 与 `software/atri/config/robot.json`
> 仍待回灌——改重量方案时一并重算。

**已修正的三个认识错误：**

1. **"结构减重数学上堵死"是错的。** 同尺寸下你们的结构件（552 g）比参考机放大到同尺寸还轻 15%
   —— 没有浪费。多出的质量里 220 g 是赛题要求的额外 4 个自由度，235 g 是原来更高的机身。
2. **"额定 1.0 N·m 无权威出处"这个判断本身是错的。** 官方额定 **0.98 N·m @12V** 确有出处
   （DFRobot SER0070 + 飞特 STS3235 规格书，见 `design/handoff/STS3215-官方规格书核验.md` §4.1）；
   真正无出处的是"堵转 × 50% = 1.47 N·m"这个**选型习惯判据**，它比官方额定乐观 50%。
3. **速度口径**：0.222 s/60°（= 270 °/s）有实物包装标签出处；早期的 0.18 s/60° 与 300 °/s 均无出处，已作废。

**仍未消除的唯一硬不确定项**：STS3215 的真实连续扭矩与温升。
→ **建议动作：买 1 只 12V 版实测（约 90 元）**，这比换构型、换材料、买整机都便宜。

## 与外部部件库的协作

本项目缺少工业制品的世界知识（舵机孔位、轴承规格、走线工艺等），
这部分由外部部件库（Gemini 网页版）补充，协作方式：

```
Gemini  →  真实元件参数（型号/尺寸/质量/协议/工艺坑）
              ↓  人肉录入 design/components.json + design/cad/standards.py
本项目  →  check_fit.py 校验（装得下吗？重量对吗？力矩还够吗？）
              ↓
          反馈问题给对方，进入下一轮
```

**分工原则**：对方提供参数，本项目负责**一切需要与模型对照的判断**
（对方看不到模型，此类判断必错）。

已完成 3 轮，交接包见 `design/handoff/`。
