## 4. 诚实声明（必须贴进 xlsx 备注）

1. **实际支出目前 ≈ 0**（样机未采购、未制造）。表内是预算/询价，随行就市。
2. **没有发票号。** 不要在模板「实际支出」列填上述区间冒充已付款。
3. 续航若按赛题 30 min，电池要从 2000 mAh 换成标称 ≥4.53 Ah，成本与整机重量上修；现表按现行选型。
4. 结构件质量以 CAD 实算 **1383.8 g / 81 件** 为上限；BOM 旧「1790 g」是历史口径。
5. 成本估算.md 的 2788–3456 是「自备打印机、只算耗材」粗估，且打印质量口径偏旧；**申报用 BOM 两档**。
6. 队员自备消费级 FDM：打印工时与打印机本体不计费。
