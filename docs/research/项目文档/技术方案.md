# A.T.R.I. 技术方案

当前方案是 **ATRI-v2 A 路线**：20 DOF、无 `hip_yaw`，20×STS3215-C018 12 V（额定 0.98 N·m），6061 铝夹层 + 2.4 mm PETG，单电池，单舵机两指夹爪。权威参数以 [`design/v2/profile.py`](../../../design/v2/profile.py) 与 [`design/v2/README.md`](../../../design/v2/README.md) 为准。

旧 22 DOF 打印件方案整包在 [`archive/v1-22dof/`](../../../archive/v1-22dof/README.md)，本文不引用那套数字。

## 1. 设计目标

- 身高 ≤ 60 cm，体宽 ≤ 30 cm（赛题包络量法待 G3 确认）
- 零位 CAD 外包络 **466.5 × 188 × 295 mm**
- 自由度：**20 DOF**（头 2 · 躯干 2 · 腿 4+4 · 臂 4+4），不恢复 `hip_yaw`
- 转向：左右髋 roll 反对称占位，**不是真实偏航**，G4 开放
- 电源：单只 3S 2200 mAh；不得写 30 分钟续航
- 运行：默认离线

**不是已打样整机。** G0–G4 全部 OPEN。已计质量约 2469 g，超 2450 g 硬顶且未计齐。

## 2. 系统架构

```
任务卡 JSON
   ↓
大脑（Brain）: FSM + 技能库 + 任务调度
   ↓                       ↑ 感知结果
小脑（Cerebellum）: 步态生成 / 关键帧动作 / 舵机控制
   ↓
20 路总线舵机
```

- 大脑：视觉/语音接入、二维码 JSON、FSM。
- 小脑：步态、动作库、限位；`NaN/Inf` 拒绝下发。
- 总线：开发期 `MockServoBus`；真机 `Sts3215Bus`。

## 3. 仿真

默认世界 `webots/worlds/atri_v2.wbt`：重力 0、盒体、20 电机、`atri_controller`。这是运动学联调，**不是 G4**。带重力派生世界另生成，不得覆盖默认世界。

## 4. 五项任务

与 `software/atri/task_cards/` 同一套 JSON。无硬件 `run_demo.py --fast` 只证明调度，不证明赛场完成度。
