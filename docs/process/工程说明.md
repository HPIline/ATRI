# A.T.R.I. 工程说明

本项目面向双足桌面人形机器人系统的跨平台研发与验证，基准开发环境以通用 Linux aarch64 为主，辅助环境涵盖 x86_64 仿真与独立 CAD 工具链。

---

## 1. 开发基准环境：Linux aarch64 + Python 3.14

项目核心业务代码基于 Python 3.14 标准库设计，板载与主开发环境要求统一为 Linux aarch64 与 Python 3.14。CI 矩阵仅维护 Python 3.14。

### 1.1 在 Linux aarch64 系统上编译安装 Python 3.14

在主流 Linux 发行版（如 Debian / Ubuntu aarch64）上，若官方软件源尚未提供 Python 3.14，可通过源码编译安装：

```bash
# 1. 安装基础构建工具及必要头文件
sudo apt update
sudo apt install -y build-essential libssl-dev zlib1g-dev \
    libbz2-dev libreadline-dev libsqlite3-dev curl git \
    libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev

# 2. 下载并解压 Python 3.14 源码包（以实际稳定版本为准）
curl -O https://www.python.org/ftp/python/3.14.0/Python-3.14.0.tar.xz
tar -xf Python-3.14.0.tar.xz
cd Python-3.14.0

# 3. 配置与编译安装（安装至 /usr/local，避免覆盖系统自带 python3）
./configure --enable-optimizations --with-lto
make -j$(nproc)
sudo make altinstall

# 4. 验证安装
python3.14 --version
```

### 1.1b macOS 本地开发：仓库内自带 Python 3.14（推荐）

macOS 上多半没有 3.14（系统自带 3.9.6、Homebrew 常见 3.13），而项目基准是 3.14。
为了不让"本地 3.9 / CI 3.14"这种错位反复制造假问题，本仓库**直接把 3.14 装进仓库内**：

```bash
# 一次性：下载 python-build-standalone 的预编译包并解压到 .python/
#   （国内镜像可用；版本号、来源 URL 与 tar.gz 的 sha256 见 .python/VERSION.txt）
curl -sSL -o /tmp/py314.tar.gz \
  "https://mirror.nju.edu.cn/github-release/astral-sh/python-build-standalone/20260901/cpython-3.14.7%2B20260901-aarch64-apple-darwin-install_only.tar.gz"
tar xzf /tmp/py314.tar.gz && mv python .python

./.python/bin/python3 -V     # 期望：Python 3.14.7
```

**为什么装进仓库而不是装到系统**：不动系统、不需要管理员权限、不影响其它工程。
`.python/` 已在 `.gitignore` 里（解释器不入库）——**所以出处与校验和记在这里**（跟踪入库的文件），
本地另有一份抄件在 `.python/VERSION.txt`：

| 项 | 值 |
|---|---|
| 版本 | CPython **3.14.7** |
| 来源 | python-build-standalone（astral-sh），标签 `20260901` |
| 资产 | `cpython-3.14.7+20260901-aarch64-apple-darwin-install_only.tar.gz` |
| 镜像 URL | `https://mirror.nju.edu.cn/github-release/astral-sh/python-build-standalone/20260901/` |
| tar.gz sha256 | `30daa970c7d223530120f1693cd3c6fa4c0c0d31ef158710b0dd77f286a5b23e` |
| 大小 | 25.4 MB（解压后约 70 MB） |

其他平台换资产名即可（`x86_64-apple-darwin` / `aarch64-unknown-linux-gnu` 等），
同一标签下都有；树莓派部署同样可用这一套（免得在板子上源码编译）。

配套虚拟环境（人脸 / 二维码任务用的可选依赖）：

```bash
./.python/bin/python3 -m venv .venv-face
./.venv-face/bin/pip install -i https://pypi.tuna.tsinghua.edu.cn/simple \
    "opencv-contrib-python==4.11.0.86" numpy pillow qrcode pyarrow
```

> ⚠ **不要把 numpy pin 到 `<2`**：numpy 1.x 没有 3.14 的 wheel。
> 2026-09-13 实测 `Python 3.14.7 + numpy 2.5.3 + opencv-contrib-python 4.11.0.86` 可用。

**验证基准**（2026-09-13 实测，两处环境结果一致）：

| 命令 | 期望 |
|---|---|
| `cd software/atri && python3 -m unittest discover -s tests`（升级前系统 3.9.6） | 579 项全绿 |
| `cd software/atri && ../../.python/bin/python3 -m unittest discover -s tests`（3.14.7） | **579 项全绿** |
| 同上但用 `.venv-face`（装齐依赖） | **579 项、0 跳过** |

### 1.1c 本机解释器清单（2026-09-13 实测，避免"到底用哪个 Python"的混乱）

| 环境 | 解释器 | 用途 | 状态 |
|---|---|---|---|
| `.python/` | **3.14.7** | **项目基准**：主软件栈、测试、人脸/二维码工具 | ✅ 本机新增，仓库内自带（`VERSION.txt` 记来源与 sha256） |
| `.venv-face/` | **3.14.7** | 人脸（T-01）/ 二维码（T-02）可选依赖（opencv-contrib、numpy、pyarrow、qrcode） | ✅ 已从 3.9.6 迁到 3.14 |
| `.venv-cad/` | 3.9.6 | CAD / CadQuery 装配与干涉普查 | ⚠️ **有据的例外**：CadQuery 2.5.2 不支持 3.14，见 §2 |
| `.venv-ppt/` | 3.13.3 | 答辩 PPT 生成流水线 | ⚠️ **遗留环境**：`ppt/` 下流水线脚本已按 `.gitignore` 移出仓库（只保留成品 PPTX），**仓库内已无代码依赖它**；若本机不再需要生成 PPT，可直接删掉这个目录 |

**判据**：凡是有仓库代码依赖的环境，一律对齐 **3.14**；例外的必须写明技术原因（CadQuery）
或明确标注为"无代码依赖的遗留"。这样"我该用哪个 Python"不再靠猜。

**怎么验证用的是 3.14**：

```bash
./.python/bin/python3 -V            # Python 3.14.7
./.venv-face/bin/python -V          # Python 3.14.7
cd software/atri && ../../.python/bin/python3 -m unittest discover -s tests
```

### 1.2 可选视觉依赖：opencv-python-headless

在无图形界面的嵌入式板卡或服务器上，若需要接入真机摄像头与视觉算子，请安装 headless 版本的 OpenCV：

```bash
python3.14 -m pip install opencv-python-headless
```

注意：主包感知接口核心逻辑支持纯标准库运行与 Mock 接口，未安装 OpenCV 时测试与模拟 demo 仍可全绿执行。

### 1.3 TTS 语音系统包与外部引擎

在 Linux 系统下，语音模块会按顺序探测以下本地命令行工具或引擎：

1. `piper`：轻量级高质量本地离线神经网络语音合成。
2. `espeak-ng`：低资源占用的本地语音合成工具。
3. `espeak`：旧版 espeak（部分镜像只有这个）。
4. `spd-say`：Linux 桌面常见的 speech-dispatcher 客户端。

在 Debian/Ubuntu 上可通过 apt 安装后两者作为基础输出：

```bash
sudo apt install -y espeak-ng speech-dispatcher
```

可通过设置环境变量 `ATRI_TTS` 指定或强制优先调用的后端命令。若系统未安装上述任何引擎，软件栈自动回退至 `MockTTS` 记录内存日志，保证任务链路不崩溃。

## 2. 独立 CAD 环境：Python 3.9.6 + CadQuery

当前机构 CAD 在 `design/v2/`（Python 3.12 CadQuery，`.venv-cad`）。旧 22 DOF 打印件 CAD 备份在 `archive/v1-22dof/design/cad/`。

```bash
PYTHONPATH=design .venv-cad/bin/python -m v2.generate
PYTHONPATH=design .venv-cad/bin/python -m v2.cad_audit
```

迁移注意：未来若将 CAD 迁移至 Python 3.14，需升级至 CadQuery 2.8+ 体系及其对应平台的 cadquery-ocp 预编译轮子。

## 3. Webots 仿真环境（x86_64）

Webots 仿真工程位于 `webots/` 目录，推荐在具备图形加速的 x86_64 工作站运行：

- 推荐版本：Webots R2025a
- 世界模型：`webots/worlds/atri_v2.wbt`（20 个驱动关节，重力 0 运动学联调）
- 批处理与离线测试：
  - 本地离线逻辑回归测试（41 项测试）：
    ```bash
    python3.14 -m unittest discover -s webots/tests
    ```
  - 无头批处理验证脚本：`webots/tools/run_webots_batch.sh`（Linux x86）或 `run_webots_batch.ps1`（Windows）。

## 4. 附录：macOS 与 Windows 开发支持

### 4.1 macOS（Apple Silicon）

- 核心要求：通过 Homebrew 或官方安装包安装 Python 3.14。
- 语音交互：原生支持系统级 `say` 命令（通过 `MacOSTTS` 实现），无需额外安装 Linux TTS 引擎。
- 编译与自检：
  ```bash
  cd software/atri
  python3.14 -m compileall -q atri run_demo.py
  python3.14 -m unittest discover -s tests
  ```

### 4.2 Windows

- 建议通过官方安装包安装 Python 3.14，并将 Python 添加到系统 PATH。
- 可选依赖通过标准 pip 安装；如需跑 Webots，可使用 `webots/tools/run_webots_batch.ps1` 进行自动化批处理调用。
