# A.T.R.I. 工程说明

本项目面向双足桌面人形机器人系统的跨平台研发与验证，基准开发环境以通用 Linux aarch64 为主，辅助环境涵盖 x86_64 仿真与独立 CAD 工具链。

---

## 1. 开发基准环境：Linux aarch64 + Python 3.14

项目核心业务代码基于 Python 3.14 标准库设计，板载与主开发环境要求统一为 Linux aarch64 与 Python 3.14。CI 矩阵仅维护 Python 3.14。

### 1.1 在 Linux aarch64 系统上编译安装 Python 3.14

在主流 Linux 发行版（如 Debian / Ubuntu aarch64）上，若官方软件源尚未提供 Python 3.14，可通过源码编译安装：

```bash
# 1. 安装基础构建工具及必要头文件
sudo apt update
sudo apt install -y build-essential libssl-dev zlib1g-dev \
    libbz2-dev libreadline-dev libsqlite3-dev curl git \
    libncursesw5-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev libffi-dev liblzma-dev

# 2. 下载并解压 Python 3.14 源码包（以实际稳定版本为准）
curl -O https://www.python.org/ftp/python/3.14.0/Python-3.14.0.tar.xz
tar -xf Python-3.14.0.tar.xz
cd Python-3.14.0

# 3. 配置与编译安装（安装至 /usr/local，避免覆盖系统自带 python3）
./configure --enable-optimizations --with-lto
make -j$(nproc)
sudo make altinstall

# 4. 验证安装
python3.14 --version
```

### 1.2 可选视觉依赖：opencv-python-headless

在无图形界面的嵌入式板卡或服务器上，若需要接入真机摄像头与视觉算子，请安装 headless 版本的 OpenCV：

```bash
python3.14 -m pip install opencv-python-headless
```

注意：主包感知接口核心逻辑支持纯标准库运行与 Mock 接口，未安装 OpenCV 时测试与模拟 demo 仍可全绿执行。

### 1.3 TTS 语音系统包与外部引擎

在 Linux 系统下，语音模块会按顺序探测以下本地命令行工具或引擎：

1. `piper`：轻量级高质量本地离线神经网络语音合成。
2. `espeak-ng`：低资源占用的本地语音合成工具。
3. `espeak`：旧版 espeak（部分镜像只有这个）。
4. `spd-say`：Linux 桌面常见的 speech-dispatcher 客户端。

在 Debian/Ubuntu 上可通过 apt 安装后两者作为基础输出：

```bash
sudo apt install -y espeak-ng speech-dispatcher
```

可通过设置环境变量 `ATRI_TTS` 指定或强制优先调用的后端命令。若系统未安装上述任何引擎，软件栈自动回退至 `MockTTS` 记录内存日志，保证任务链路不崩溃。

## 2. 独立 CAD 环境：Python 3.9.6 + CadQuery

CAD 装配、骨架求解与干涉普查位于 `design/cad/`。由于 CadQuery 2.5.2 依赖底层的 OpenCASCADE 绑定库，暂不支持 Python 3.14，因此 CAD 工具链使用独立的 `.venv-cad` 环境：

- Python 基准版本：**3.9.6**
- 核心依赖：`cadquery==2.5.2`
- 构建入口脚本：`design/cad/build.sh`

```bash
# 激活 CAD 专用虚拟环境并执行快速构建自检
source .venv-cad/bin/activate
bash design/cad/build.sh --fast
```

迁移注意：未来若将 CAD 迁移至 Python 3.14，需升级至 CadQuery 2.8+ 体系及其对应平台的 cadquery-ocp 预编译轮子。

## 3. Webots 仿真环境（x86_64）

Webots 仿真工程位于 `webots/` 目录，推荐在具备图形加速的 x86_64 工作站运行：

- 推荐版本：Webots R2025a
- 世界模型：`webots/worlds/atri_22dof.wbt`（包含 22 个驱动关节与机身动力学）
- 批处理与离线测试：
  - 本地离线逻辑回归测试（40 项测试）：
    ```bash
    python3.14 -m unittest discover -s webots/tests
    ```
  - 无头批处理验证脚本：`webots/tools/run_webots_batch.sh`（Linux x86）或 `run_webots_batch.ps1`（Windows）。

## 4. 附录：macOS 与 Windows 开发支持

### 4.1 macOS（Apple Silicon）

- 核心要求：通过 Homebrew 或官方安装包安装 Python 3.14。
- 语音交互：原生支持系统级 `say` 命令（通过 `MacOSTTS` 实现），无需额外安装 Linux TTS 引擎。
- 编译与自检：
  ```bash
  cd software/atri
  python3.14 -m compileall -q atri run_demo.py
  python3.14 -m unittest discover -s tests
  ```

### 4.2 Windows

- 建议通过官方安装包安装 Python 3.14，并将 Python 添加到系统 PATH。
- 可选依赖通过标准 pip 安装；如需跑 Webots，可使用 `webots/tools/run_webots_batch.ps1` 进行自动化批处理调用。
