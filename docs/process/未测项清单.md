## 0. 一句话

**我们还没有样机。** 因此赛题要的绝大多数性能指标，目前都只有"设计值 / 仿真值 / 数据集值"，
没有一条是**这台机器人**在**真实赛场**上量出来的。
本表把每一处这样的缺口写明：**现在在哪份文档里被写成什么样、为什么没测、怎么才能测**。

第 12 轮在无样机条件下闭合了若干**代码路径 / 几何 / 脚本**（见 §5）。它们**不**抬升 A1–A5、B1、B7、B8 的实机状态。
**不要把 LFW / 合成图从「已闭合」上抬到实机。**

标记约定：

| 标记 | 含义 |
|---|---|
| ⛔ | **阻断级**：没有它，赛题的关键判据回答不了 |
| ⚠️ | **重要级**：影响分数或选型，但可以先用现有手段逼近 |
| ▫️ | **背景级**：影响精度/可移植性，答辩不会被追问 |
| ❓ | **不是"未测"，是"未有定义"**：口径要主办方确认 |

## 6. 使用方式（写给答辩与材料）

1. **写材料时**：任何一句涉及"能做到什么程度"的话，先在本表搜一遍；
   命中 ⛔/⚠️ 的，写成"设计值/待实测"，不要写成结论。
2. **被追问时**：直接答"这一项我们标为未测，测它需要 X"——比含糊带过可信。
3. **闭合一项时**：更新本表（移行 + 日期 + 证据路径 + **口径一列**），并回填所有引用它的文档；
   若口径变了，按仓库惯例**保留订正痕迹**，不静默改写。
4. **第 13 轮材料**：计划书 / PPT 文案引用 §5 时必须带口径括号；提交清单见 `docs/contest/提交材料清单.md`。
