## 四、单一实体证据

```
【改前】mirror=False: solids=3 valid=True  真体积Σ=22378.6（真质量 28.42 g）
        solid0: V=21011.4  x[−48, 74] y[−30, 30] z[−16, 16]
        solid1: V=  683.6  x[ 61, 69] y[ 16, 24] z[−16, −2.4]   ← 前垫（悬空）
        solid2: V=  683.6  x[ 61, 69] y[−24,−16] z[−16, −2.4]   ← 前垫（悬空）
【改后】mirror=False: solids=1 valid=True V=20607.4 m=26.17 g
【改后】mirror=True : solids=1 valid=True V=20607.4 m=26.17 g
```

- 根因：旧版前唇缺口 `box(16, 62, 1.4, at=(67, 0, −3.2))` 把 x∈[59,74] 的鞋底板底面削掉 1.2 mm，
  而两只前垫正好落在 x∈[61,69] ⇒ **它们脚下的落脚面被切掉了**，只与上方纵梁留 2.0 mm 空隙。
- 新版把着地结构整体做在 **z ≤ −3**（鞋底底面以下），并让腹板/斜肋**压进鞋底板 1.5 mm**，
  不再依赖共面贴合；实测 `len(solids())=1`、`isValid()=True`，`build_all` 几何列 ✅。
- 该项已写成门禁 `test_foot_is_single_printable_solid`，以后回归会直接报错。

## 五、承力路径说明

**旧版（问题所在）**：舵盘 → 踝叉臂（**只有 +Y 一侧**，y=24.05…27.05）→ 3 mm 鞋底板 → 板上纵梁/横梁
→ 四只 Φ8 圆柱垫。叉臂在 y≈25.5、垫块在 y=±20：最近的一对垫只差 5.5 mm，**远侧那对要横穿 45.5 mm 的 3 mm 薄板**，
而四只垫又是互不相连的孤立接触点 ⇒ 就是汇报 §5 说的"踩高跷"。附带的第二处：前面两只垫根本没连上（§四）。

**新版（力线短、断面连续）**：

```
舵盘 ──4×M2.5──▶ 踝叉臂（y=24.05…27.05，z=−3…16）
                     │  叉臂正下方就是鞋底板边带 y∈[21.75, 30]（不是踝窝）
                     ▼
              ┌─ 前斜肋：x=+17 → +63.5，深 13.5 → 0（与叉臂同一 Y 平面）
              └─ 后斜肋：x=−17 → −41.0 ，深 13.5 → 0
                     ▼
        垫条工字梁（顶翼缘 = 鞋底板 60×3；腹板 3×54×11.5；底翼缘 54×12×3）
                     ▼
        前后两条着地面 2×54×12 = 1296 mm²（全机唯一最低平面 z=−16.00）
```

- **斜肋为什么"叉臂端最深、垫条端收尖"**：把脚看成"踝部固定、垫条受地面反力"的悬臂，
  弯矩在叉臂处最大、到垫条处归零，所以断面深度按同一趋势收——这是工程判断，**未做 FEA**（见 §七）。
- **垫条为什么是工字梁**：地面反力沿 Y 分布、载荷只从 y≈25.5 一侧进，靠"底翼缘 + 全宽 54 的腹板 + 鞋底板"
  形成的工字截面把力摊平；腹板同时是垫条的抗弯主材。
- **开窗位置**：前场中央 x∈[40, 58]（踝窝前沿 → 前垫条腹板之间）不承担上述任何一段力线，
  且 X 从 +40 起 ⇒ 左右踝窝都到不了那里 ⇒ 左右两件仍然**完全同件**（实测 V 相同）。
- 承力面壁厚全部 **3.0 mm**（`FDM.wall_mm`，与仓库既有口径一致；未新编材料参数）。
