## 1. 做了什么

答辩 PPT 写过「头部两轴对准人脸目标框」，原先真识别通路识别完只 TTS，头不转。本线程在技能层补开环随动：

1. **真识别成功且有 bbox**：框中心相对画面中心的像素偏差 → `head_yaw` / `head_pitch`，经 `cerebellum.set_pose` 下发。默认 **0.1 °/px**（每 10 px ≈ 1°），`clamp_angle` 到 `head_yaw ±90`、`head_pitch ±45`。
2. **无人脸 / 拒识**：保持，不调用 `set_pose`，结果 `gaze="hold"`。不对噪声或未过阈值的框转。
3. **退化通路只有姓名没有 bbox**：不瞎转，`gaze="skipped"`。观测里若带了 bbox 仍开环对准。
4. 增益 / 符号 / 画面尺寸可由任务卡 `params` 覆写；`T-01_face.json` 未写，走默认。

公式、限位、未标定声明见 `design/handoff/T-01-头部随动.md`。像素当量**未标定**，材料只能写「开环对准逻辑已接」，不能写成对准精度。

符号约定（未装配标定，见未测项 C2）：

- 画面右偏 → 右转 → `yaw_sign = −1`（本仓库 `+head_yaw` 视为俯视 CCW）
- 画面下偏 → 低头 → `pitch_sign = +1`

## 2. 行为对照

| 输入 | 转头 | `gaze` |
|---|---|---|
| 真识别 + bbox + cerebellum | `set_pose({head_yaw, head_pitch})` 一次 | `tracked` |
| 无人脸 | 不调用 | `hold` |
| 拒识（有框、未过阈值） | 不调用 | `hold` |
| 空帧 | 不调用 | `skipped` |
| 退化通路仅姓名 | 不调用 | `skipped` |
| 退化通路姓名 + bbox | 调用 | `tracked` |
| cerebellum 为 None | 不调用 | `skipped` |

现有真识别 / 拒识断言全部保留：认不出仍不编造姓名，`source` 仍标明。
