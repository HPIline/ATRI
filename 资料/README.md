# 资料（归档，不参与构建）

这里放调研、过程记录和参赛材料。主路径在仓库根：

| 要做什么 | 去哪 |
|---|---|
| 跑软件 / 测 | `软件/atri/`（`python3 run_demo.py --fast`） |
| 仿真 | `webots/` |
| 运动学、URDF、交接包 | `design/`（`handoff/` 只留现行交付物） |
| CAD 出零件 | `design/cad/build.sh` |
| 答辩 PPT | `ppt/` |

不要从本目录跑 CI。测试入口仍是 `软件/atri` 和 `webots/tests`。
