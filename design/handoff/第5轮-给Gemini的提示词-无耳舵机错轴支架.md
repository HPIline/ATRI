# 第 5 轮 · 给 Gemini 的提示词：无耳总线舵机的「小轴距错轴支架」

> 直接复制给 Gemini 网页版。
> **本轮范围**：只要**结构做法与量级**，不要判断「我这台机装不装得下」（你看不到模型，这类判断必错）。
> 上一轮（K1–K8）的方法论已采纳；K6 的「靠安装耳定轴距」对本机不成立，需要一版**专门针对无耳舵机**的支架做法。

---

## 背景（一句话）

A.T.R.I.：22 DOF 桌面双足，**22 × 飞特 STS3215**（12V）。结构件 PETG FDM。
模型是真 B-rep，装配由代码按 URDF 摆放。

**已闭环、不必再给的数据**（官方规格书 + 实物 B-rep 实测）：

| 项 | 值 |
|---|---|
| 机体 | 45.2 × 24.7 × 35.0 mm；**35 是沿输出轴的厚度** |
| 轴心偏置 | 距一端面 10.2、距另一端面 35.0（轴心不在长度中点） |
| 安装接口 | **无安装耳**。两端面各 4×M2.5，方形 9.9×9.9 = 节圆 Φ14 |
| 输出 | 25T 花键 OD5.9 + Φ20×2.5 凸台 + 金属舵盘 4×M2.5 @ PCD Φ14（舵盘外购） |
| 副轴 | Φ6，伸出 4.1 mm；第二支点用 MF106ZZ（Φ6×Φ10×3，法兰 Φ11.2） |
| 髋/肩轴距 | yaw/roll/pitch **两两正交、间距 19.6 mm**（运动学已冻，不改） |

---

## 我已经排除的路（不要再建议）

1. **把两只舵机机体都以关节原点为中心、共面交叠**——19.6 < 35，物理上不可能。钟点翻转 180° 也消不掉（互咬在沿轴方向）。
2. **靠安装耳厚度拼出轴距**——STS3215 没有耳；TonyPi 那套对 LX-824HV 成立，对本机不成立。
3. **加大轴距 / 删自由度 / 换有耳舵机**——赛题把 22 DOF 和两个躯干关节锁死；选型已定。
4. **把舵机塑料壳体当承力件、不对侧做副轴支撑**——已列为否决项。

我准备走的方向（请在此基础上给**可制造的支架形态**，而不是再讨论要不要错轴）：

> 轴距 19.6 mm 只给「输出轴 + 薄支架」住；两只机体沿**各自输出轴**向外错开，
> 用单侧臂 / 不对称抱箍把下一级轴线拉回来。

## 本轮任务（S1–S6）

### S1 无耳舵机的夹持形态（最高优先级）

市售「标准舵机 U/L 型支架」几乎都按**耳孔族**开孔，不能直接拧到 STS3215 上。

请给：

- 只利用「两端面 4×M2.5 / PCD14」时，工程上常见的夹持形态（端板对穿、单侧端板 + 副轴轴承、抱箍+端面螺钉……）；
- 每种形态：**螺钉走哪条轴、力怎么传到支架、批头从哪边伸进去、最小支架厚度量级**；
- 哪些形态适合「下一关节轴距只有 15–25 mm」，哪些只适合单独一个关节。

### S2 正交两轴、轴距 19.6 mm 的错轴支架（本轮核心）

给一套**针对无耳、有副轴**的髋/肩簇做法：

- 第一级输出如何接到第二级（金属舵盘 → ? → 第二级轴线）；
- 第二级机体往哪个方向躲开（沿自身轴 / 沿第一级轴 / 两者都要）；
- 错开量级：至少错开「一个机身厚度 35 mm」是否必要，还是错开「半长 22 mm」就够；
- 单侧臂 vs 双侧 U：在 19.6 mm 轴距下哪个更现实；
- 副轴第二支点放在哪一块板上，才不会和第一级打架。

请用**文字 + 简单 ASCII 或条目分解**描述载荷路径（单脚支撑、约 1.2–1.5 N·m 反扭矩从脚走到骨盆）。

### S3 出线与装配顺序

- 两只无耳舵机错轴后，3-Pin 线座通常朝哪、彼此至少留多少空间；
- 推荐装配顺序（先拧哪一级的端面螺钉、哪一步之后批头就伸不进去）；
- 「装完才发现中间那颗 M2.5 没通道」的典型死法，以及怎么在分件时预防。

### S4 打印件 vs 铝件的分界（只给规格画像，不给店铺）

髋/肩簇里：

- 哪些面必须金属（受剪的舵盘连接、受弯的单侧臂）；
- 哪些可以 PETG（座口、挡线、非承力罩）；
- 铝件的**规格画像**：板厚量级、孔系（必须是 PCD14 / 9.9 方阵，不是标准舵机耳孔）、是否需要二次加工。

Feetech 官方支架存在但「不单发」、通用 U 型架孔系不对——这两点我已知，不必重复。请回答：**二次加工通用件**和**按 PCD14 自己出一张激光/CNC 板**，哪个更适合 8–12 件的小批量。

### S5 不要碰的边界

请明确：

- 19.6 mm 轴距 + 无耳 + 必须副轴支撑，这套约束下**哪种漂亮的嵌套方案其实做不到**；
- 轴距小到多少（区间）就必须改运动学，而不是再改支架。

### S6 可写成断言的 8 条检查项

每条：检查什么、阈值量级、假阳性。例如：

- 两机体沿轴投影重叠长度；
- 副轴轴承中心与输出轴同轴度；
- 线座净空；
- 端面螺钉的批头通道。

## 硬性要求

1. 每条给：**做法 / 量级区间 / 常见错误 / 来源等级 / 置信度**。
2. 来源等级：A 标准原文｜B 厂商文档｜C 一手实测｜D 经验。本轮允许 D，但必须标出来。
3. **找不到就写「未找到」，禁止编造精确孔距/板厚到 0.1 mm。** 经验给区间。
4. **不要做「你这台 19.6 mm 装不装得下」的判断**——那是我用模型算的。
5. **不要建议换 STS3215、改 22 DOF、改轴距。**
6. 输出用 checklist / 分件示意，我要拿去改 CadQuery 零件，不是拿去写论文。
