## 2. 数据流

```
可选麦克风 PCM
 └─ VoskKeywordRecognizer.recognize(audio)     惰性 import vosk；没装 → available=False
      └─ match_keyword(转写, 白名单)           未命中返回空串，不编造
           └─ KeywordSpeechPerception.detect_speech → {keyword, found}
                └─ DanceSkill
                     ├─ 通道未接入          → keyword = params（source=params）
                     ├─ 通道已接入但无词/非法词 → TTS「我没听清」+ failed
                     └─ 白名单命中          → cerebellum.dance(bars) + TTS「舞蹈结束」
```

本地 wav 播放是尽力而为（`afplay` / `ffplay` / `aplay`），失败标 `unavailable` / `missing`，**不声称与节拍同步**。

## 3. 接口

| 符号 | 位置 | 行为 |
|---|---|---|
| `VoskKeywordRecognizer` | `atri/voice/vosk.py` | 惰性 import vosk；模型路径 `ATRI_VOSK_MODEL` |
| `build_recognizer()` | 同上 | 引擎+模型齐全才返回实例，否则 `None`（不降级成 Mock） |
| `KeywordSpeechPerception` | 同上 | 把识别器接到 `detect_speech` |
| `match_keyword` | 同上 | 纯字符串白名单，零第三方 |
| `DanceSkill` | `atri/skills/dance.py` | **默认行为不变**；不强制注入 recognizer |
| `dance_eval.py` | `software/atri/tools/` | 关键词注入统计命中/拒识，不依赖真麦 |

核心包 `pyproject.toml` 的 `dependencies = []` 不变。vosk 不进主依赖。

## 4. 无 ASR / 有引擎 两种口径

### 4.1 无 ASR（当前本机默认）

- `python3 -c "import vosk"` → `ModuleNotFoundError`
- `VoskKeywordRecognizer().available()` → False
- 单元测试里真引擎用例 **skip**
- 任务演示：`MockPerception(speech={"keyword":"跳舞"})` 或任务卡 `params.keyword`
- **不得**把 Mock 命中率写成「离线识别率」

评测脚本对**注入用例**的门闩结果（代码路径，不是 ASR）：

- 白名单命中：`请跳舞` / `挥手你好` / `鞠躬致谢` → 对应关键词
- 拒识：`起飞` / 空串 / 闲聊 → 空串，技能 TTS「我没听清」并失败
- 通道未接入 → `source=params`

### 4.2 有引擎时（本机，非赛场噪声）

后装步骤（**不要装到系统路径**，本线程未执行 pip）：

```bash
# 在项目 venv 内，不要 python3 -m pip install vosk 到系统
# 1. 安装 vosk 到 venv
# 2. 下载小模型（如 vosk-model-small-cn-0.22）到本地目录
# 3. export ATRI_VOSK_MODEL=/path/to/vosk-model-small-cn-0.22
# 4. python3 software/atri/tools/dance_eval.py
```

命中率只允许写成：

> 本机安静环境、关键词注入 / 指定 wav 上的离线命中率；**不是**赛场噪声、**不是**样机麦。

本轮本机 **未装 vosk、未下载模型**，因此 **没有** 可引用的本机 ASR 命中率数字。

## 5. 白名单

| 输入 | 期望 |
|---|---|
| 通道未接入 | `source=params`，默认「跳舞」 |
