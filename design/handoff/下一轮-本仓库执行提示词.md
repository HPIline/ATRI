## 零、先接受一个判断

**用 Python 手搓基元（长方体/球/胶囊）当 CAD 用，是死路。**
它做不出可制造零件，也无法与 SolidWorks / 仿真 / 后续设计对接。

**但 Python 本身不是问题**——问题是没接 CAD 内核。

现已验证：**CadQuery 2.5.2 + OpenCASCADE 7.7 可在本机跑通**
（Python 3.9.6 / macOS arm64），具备圆角、抽壳、布尔、STEP/STL 导出。
`design/cad/` 已搭好骨架并验证过 3 个零件。

**新架构**：

```
robot_model.json  (运动学/包络/质量，基元，继续用于校验与仿真)
      +
components.json   (外部元件参数)
      ↓
cad/standards.py  (标准件参数，unknown 会拦截构建)
      ↓
cad/parts.py      (CadQuery 参数化建模 → 真 B-rep 实体)
      ↓
STEP (进 SolidWorks)  +  STL (打印)
      ↓
check_fit.py 复核包络与质量
```

## 二、任务清单

### 任务 1（前置）：等 Gemini 回填机械接口

**当前唯一阻塞项**：`STS3215.body_mount_spacing_mm = unknown`。

拿到数据后回填 `design/cad/standards.py`，把 `verify` 改成
`verified` 或 `provisional`。

**在拿到之前**：可以先做不依赖它的零件（连杆、舵盘转接、传感器支架）。

### 任务 2：补齐 `standards.py`

按 Gemini 第 2 轮回复补：
- 舵机机身孔位、副轴规格
- 舵盘节圆（Φ14 还是 Φ16，以实物为准）
- 商业支架/舵盘/轴承的规格与货源
- 打印公差（复核我暂用的 0.4/0.2/−0.05 是否合理）

**每项都要有 `verify` 状态与来源**，unknown 保持拦截。

### 任务 3：建立 22 个关节的模块库

按关节类型归并（22 个关节只需少数几种模块）：

| 模块 | 覆盖关节 | 说明 |
|---|---|---|
| `yaw_module` | 髋 yaw ×2、头 yaw | 单舵机 + 推力轴承 |
| `pitch_module` | 髋 pitch ×2、膝 ×2、踝 ×2、肩 pitch ×2、肘 ×2、头 pitch、腰 pitch | 最通用，先做 |
| `roll_module` | 髋 roll ×2、肩 roll ×2、腰 roll | 舵机 + 副轴 |
| `gripper` | 夹爪 ×2 | 平行开合 |

**每个模块产出**：舵机支架、副轴支撑、连杆接口、走线通道。

### 任务 4：四肢连杆

- 大腿 / 小腿：按 `robot_model.json` 的关节间距定长度
  （大腿 髋→膝 80mm，小腿 膝→踝 80mm）
- 上臂 / 前臂
- **连杆必须有走线孔**（22 路总线要穿过）
- 用 `link_tube()` 作基础改型

### 任务 5：装配体 + 干涉检查

- 用 CadQuery `Assembly` 组装
- **极限姿态干涉检查**（每个关节取限位两端）
- 这是 `外观尺寸零件设计Prompt.md` 里 P2 项，现在有真几何了可以真做
- 输出装配体 STEP + 干涉报告

### 任务 6：工程图（从实体投影，不再手算）

现有 `gen_drawings.py` 是从基元手算投影。改为：
- 用 CadQuery 的 `section()` / 投影生成真视图
- 或导出 STEP → 用 `build123d` 的 Draft 模块出 2D 图
- 至少出：22 关节编号图、总装三视图、爆炸图

### 任务 7：打印件清单与成本

- 每个零件的**打印方向、支撑需求、耗材估算**
- 汇总：共 __ 种 __ 件，耗材 __ g，打印时长 __ h
- 与 `check_fit.py` 的质量闭合对账

## 三、约束

1. **主仓库零第三方依赖不变**。CadQuery 只在 `.venv-cad` + `design/cad/`。
2. **`unknown` 参数必须拦截构建**，不许用臆测值出零件。
3. **每个零件必须是单实体且 `isValid()`**，有测试守护。
4. **参数不硬编码**，全部走 `standards.py`。
5. **不得改写** `软件/atri/atri/` 下的固件逻辑。
6. 删除工作树前先 `git pull --rebase origin main`。
7. 大文件（STEP/STL）超 50MB 不入库；`out/` 目录整体 gitignore。
