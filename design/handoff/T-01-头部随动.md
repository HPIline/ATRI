# T-01 头部随动（bbox → yaw/pitch）

> 状态：**逻辑层已落地，像素当量未标定**（2026-09-13）。
> 独占实现：`software/atri/atri/skills/face.py`。
> 不改识别器、FaceDB、LFW 数字。答辩 PPT「头部两轴对准人脸目标框」对应的是本文件，不是识别成功率。

---

## 1. 做什么、不做什么

真识别通路在检出合法 bbox 且识别成功后，把**框中心相对画面中心的像素偏差**开环映射成 `head_yaw` / `head_pitch`，经 `ctx.cerebellum.set_pose` 下发。

| 场景 | 动作 | 结果字段 |
|---|---|---|
| 真识别成功且有 bbox、有小脑 | 开环 `set_pose` | `gaze="tracked"` + 限位后角度 |
| 无人脸 / 拒识 | **保持**，不调用 `set_pose` | `gaze="hold"` |
| 空帧 / 名单外失败 / 无小脑 | 不转 | `gaze="skipped"` |
| 退化通路只有姓名、没有 bbox | **不瞎转** | `gaze="skipped"` |
| 退化通路观测里带了 bbox | 同样开环对准 | `gaze="tracked"` |

拒识即使有框也不转：相似度未过阈值的框当噪声，避免追假目标。

---

## 2. 公式

bbox 约定与检测器一致：`(x, y, w, h)`，像素，原点在画面左上，y 向下。

```
cx = x + w / 2
cy = y + h / 2
dx = cx − W / 2
dy = cy − H / 2

yaw   = clamp(yaw_sign   × dx × k_yaw,   −90°, +90°)
pitch = clamp(pitch_sign × dy × k_pitch, −45°, +45°)
```

默认：

| 符号 | 默认 | 含义 |
|---|---|---|
| `k_yaw` / `k_pitch` | **0.1 °/px**（每 10 px ≈ 1°） | 保守增益，未标定 |
| `yaw_sign` | **−1** | 画面右偏应对应右转；本仓库 `+head_yaw` 视为俯视 CCW（左转） |
| `pitch_sign` | **+1** | 画面下偏应对应低头；本仓库 `+head_pitch` 视为低头 |
| `W × H` | 帧 `shape`；否则任务卡；再否则 **640×480** | VGA 只是缺省，不是相机实测 |

限位走 `config.clamp_angle`，与关节表一致：`head_yaw ±90`、`head_pitch ±45`。小脑 `set_pose` 还会再钳一次。

例：640×480、框 `(0,0,100,100)` → 中心 `(50,50)` → `dx=−270`、`dy=−190` → `yaw=+27°`、`pitch=−19°`。

---

## 3. 任务卡可覆写

优先级：任务卡 `params` > 代码默认。非法 / 非正数回落默认，不把任务卡炸掉。

| 键 | 作用 |
|---|---|
| `gaze_deg_per_px` | 两轴共用增益 |
| `gaze_yaw_deg_per_px` / `gaze_pitch_deg_per_px` | 分轴增益（缺省用共用值） |
| `gaze_yaw_sign` / `gaze_pitch_sign` | 符号；实机标定 sign 后改这里 |
| `frame_width` / `frame_height` | 无 `frame.shape` 时的画面尺寸 |

`task_cards/T-01_face.json` **未写这些键**，跑默认 0.1 °/px。

---

## 4. 未标定（像素当量）

本映射**不是**针孔模型，也不是视觉伺服闭环。

- 没有相机 FOV、焦距、安装高度、头部位姿零点的实测。
- `0.1 °/px` 是保守设计值：640 宽画面从中心扫到边约 32°，落在 yaw 限位内。
- 符号按仓库关节约定选取，**舵机 sign / zero_pulse 仍未装配标定**（未测项 C2）。
- 因此材料里只能写「开环对准逻辑已接」；**禁止**写成对准精度、跟踪成功率或已通过实机验收。

真机标定建议：固定距离贴靶，量 `dx` 与实际转角，回填 `gaze_*_deg_per_px` 与 sign。
