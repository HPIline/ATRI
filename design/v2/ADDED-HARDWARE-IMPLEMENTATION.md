# 新增硬件实体

本版保留单片手臂，并把已确认的功能增补落入 CAD：第二块与主包相同的 3S 2200 mAh 电池实体（107×33×22 mm、169 g）安装在胸腔前侧独立托盘，两条绑带固定。电气串联/并联、保险丝、反接保护和充电方式仍需实物方案确认，CAD 不表示可以直接并联。

VL53L1X 测距板按 20×24 mm、2 mm 安装孔加入头部下方的小型安装座，板前保留无遮挡窗口；IMU 仍只保留未锁型号的通用安装位，避免虚构孔距。

夹爪继续采用单执行器双指机械夹持，增加可更换 TPU 接触垫和导向背托；两指没有假定由自由后盘主动同步。第二电池至少增加 169 g，当前质量会进一步超过硬顶，必须重新减重。
