# STS3215 通信协议与寄存器表（已双源核验）

> 生成日期：2026-09-11　执行：第 3 轮 T4
> 用途：ATRI 固件将来实现真实 `ServoBus` 时的唯一权威参考
> 核验方式：**两个独立来源逐地址比对**，见第 4 节

---

## 1. 物理层与总线

| 项 | 值 | 来源 |
|---|---|---|
| 总线类型 | **TTL 半双工串行总线**，单线级联 | 厂商规格 |
| **默认波特率** | **1 000 000 bps** | 寄存器 6 默认值 0 = 1 Mbps |
| 可选波特率 | 1M / 500K / 250K / 128K / 115200 / 76800 / 57600 / 38400 | 寄存器 6 取值 0–7 |
| 默认 ID | **1** | 寄存器 5 默认值 |
| ID 范围 | 0 – 253 | 寄存器 5 说明 |
| 广播 ID | **254 (0xFE)** | 官方 `scservo_def.py` |
| 最大单机 ID | 252 (0xFC) | 同上（254 保留给广播） |
| 位置分辨率 | 0–4095 对应 0–360°，**约 0.088°/单位** | 寄存器说明 |
| 中位 | **2048** | 同上 |

> ⚠️ **与 ATRI 现有假设的差异**：`standards.py` 写 `baud_bps = 1_000_000` ✅ 正确。
> 但注意总线舵机位置量程是 **0–4095**，而幻尔 TonyPi 动作组用的是 **0–1000**（中位 500）——
> **两套量纲不同，换算时不要混用**（4095 制中位 2048 ↔ 1000 制中位 500）。

## 2. 指令集（官方 `scservo_def.py`）

| 指令 | 值 | 用途 |
|---|---|---|
| `INST_PING` | 1 | 探测舵机是否在线 |
| `INST_READ` | 2 | 读寄存器 |
| `INST_WRITE` | 3 | 写寄存器 |
| `INST_REG_WRITE` | 4 | 预写（不立即生效） |
| `INST_ACTION` | 5 | 触发 `REG_WRITE` 缓存的动作 |
| `INST_SYNC_READ` | 130 (0x82) | **多舵机同步读** |
| `INST_SYNC_WRITE` | 131 (0x83) | **多舵机同步写** ← 22 路群控的关键 |

**通信结果码**：`0` 成功；`-1` 端口忙；`-2` 发送失败；`-3` 无状态包；
`-4` 包非法；`-5` 接收中；`-6` **超时**；`-7` 包损坏。

> 🎯 对 ATRI 的价值：**`SYNC_WRITE` 是 22 路关节同时下发的正道**。
> 逐个 `WRITE` 会有 22 倍总线占用与时间偏斜，步态会走形。

| 松轴 | 40 | 0 |

## 5. 对 ATRI 固件的落地建议

现状：`软件/atri/atri/cerebellum.py` 的 `ServoBus` 是**纯抽象接口**
（`set_angle(joint_id, deg)` / `read_angle(joint_id)`），没有寄存器级假设 —— **这个设计是对的**，
真实实现只需补一个 `RealServoBus` 适配层：

| ATRI 抽象 | 应映射到的寄存器操作 |
|---|---|
| `set_angle(id, deg)` | 角度 → 脉冲：`pos = 2048 + deg / 0.0879`，写 **42**（配 46 限速） |
| `read_angle(id)` | 读 **56** 位置 → 反算角度 |
| （建议新增）`health(id)` | 读 **63** 温度 / **62** 电压 / **60** 负载 / **69** 电流 / **65** 状态 |
| 22 路同时下发 | **`INST_SYNC_WRITE`(131)** 批量写 42，不要逐个写 |

**三条必须注意的坑**：

1. **量纲别混**：总线位置是 **0–4095（中位 2048）**；
   幻尔动作组的 0–1000（中位 500）是另一套，换算系数 4095/1000 ≈ 4.095。
2. **改 EEPROM 前必须关扭矩**（寄存器 40 = 0），否则写入无效甚至触发保护。
3. **过载保护要用起来**：寄存器 34/35/36 是现成的堵转保护，
   配合 63（温度）与 69（电流）回读，正好解决 `成本估算.md` 里
   "STS3215 真实连续扭矩与温升无实测"这一最大不确定项 —— **上电即可采数据**。
